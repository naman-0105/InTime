# InTime — Scheduling Platform

A simple, maintainable scheduling platform where users create event types, define availability, share booking links, and accept bookings.

## Tech Stack

- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, JavaScript
- **Database & ORM**: PostgreSQL, Prisma ORM
- **Authentication**: JWT with HTTP-only cookies

## Project Structure

```
InTime/
├── frontend/
├── backend/
├── .gitignore
└── README.md
```

## Getting Started

### 1. Backend Setup

```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
